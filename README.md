# Payload Headless vs WordPress

Landing page desarrollada con Astro para presentar las ventajas de un CMS propio construido sobre Payload CMS frente a una implementación tradicional de WordPress.

## Incluye

- Comparativa Payload CMS vs WordPress.
- Explicación de arquitectura headless.
- Diagrama interno con TypeScript y Clean Architecture.
- Stack con Next.js, Payload, PostgreSQL y TypeScript.
- Galería interactiva del dashboard y editor visual.
- Información sobre la licencia MIT y uso comercial.
- Diseño responsive.

## Desarrollo

```bash
npm install
npm run dev
```

## Producción

```bash
npm run build
npm run preview
```

## Licencia de Payload CMS

Payload CMS es software de código abierto distribuido bajo licencia MIT. La implementación y personalización mostradas en este proyecto fueron desarrolladas como una solución propia sobre esa base.
